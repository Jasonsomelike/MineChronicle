净补齐 **456 条引用**；还有实例缺图的不同 ID 减少 **209 个**。这两个数字不是新增 PNG 数量，同一资源会被不同类别和整合包复用。原有错误图片的修正也不计入“净补齐”。

上述覆盖率通过最终资源目录、统计资源表和实际 PNG 文件三方核对得到。报告没有把“能找到某张图片”视为模型正确，也没有将空气、内部技术方块或无法识别物种的统计强行配图。

## 修正内容

- 烈焰人采用原始 Java 模型的 12 根独立火棒及三圈静止位置，修复重叠。
- 末影龙恢复颈部、尾部、双翼和腿部的分段、父子关系及代表性飞行姿态，保留原始 UV 和贴图。
- 修正鸡的躯干旋转中心、女巫基础身体遗漏、僵尸村民误用职业层、豹猫皮肤和马类新旧 UV 布局。
- 实体解析支持不同模型工厂名、模型继承、数组中的部件，以及辅助函数的完整重载签名。修复 hmag 两个模型的非数值坐标。
- 扩展实际渲染器到模型/贴图的静态绑定，支持 `textures/model` 等目录，排除误配的旗帜和盾牌图案。
- 补入 Ars Nouveau 召唤物、荒野奇美拉、Goety 老巫婆、灾变、暮色森林和其他模组中的一批实体。召唤物只有在原模组确实注册原版渲染器时才复用原版模型。
- 冰火传说三类龙读取原始 Tabula 立方体、层级、旋转和随模型提供的皮肤。统计没有颜色、性别和生长阶段信息，因此显示的是明确的代表性外观。
- 箱怪补入独立箱体层及其原始变换；灾变 Maledictus 同时保留灵体和盔甲层；幻影骑士采用身体皮肤。
- Age of Mythology 遗物按模组自身的 skull 渲染配置及皮肤映射还原。物品模型增加 GUI 专用视角和组合材质解析。
- 渲染前拒绝循环父子关系、无效向量和空模型；重复提交的离屏渲染结果可安全重试。

## 尚未完整支持的情况

本次并未实现“所有模组、所有版本零缺图”。剩余主要包括 GTCEu/附属模组的动态注册物品、特殊方块实体渲染器、流体容器、部分 OBJ/材质加载器，以及分体或运行时生成的实体模型。部分生物只能取得代表性姿态或主体，不能从统计数据恢复其游戏内动态状态。

例如 Cobblemon 的通用 `pokemon` 统计不携带物种，不能据此推断具体宝可梦；不能为此虚构物种图片。对缺少完整绑定的模型保留缺图状态。剩余每个资源的实例范围、类别和初步原因均记录在分类报告中，避免以后重复无目标地试配贴图。

档案核对保持 63 个实例、97 个世界、53 个玩家、410 个快照、扫描版本 234；初始/当前时长总 tick 数分别为 104326476 / 104329932，SQLite 完整性和外键检查通过。
