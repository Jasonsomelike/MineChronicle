## 问题 1：排行页签与内容不对应，且留白太多

**截图证据**：页签「**世界排行**」是选中态（绿色），但下面的内容是「**实例排行 · 按根目录汇总**」，
列表是 `01 gtl / 144h 3m`、`02 All the Mods 10 / 141h 32m` —— **这是实例，不是世界**。

**根因假设**：`src/components/Dashboard.tsx` 里 `ranking` 状态（`'worlds' | 'instances'`）与
页签的 `aria-pressed` 或标题文案不同步。也可能页签的初始状态与实际渲染的列表不一致。

**要求**：

- 页签选中态、标题文案（「世界排行」/「实例排行」）、列表内容**三者必须一致**
- 加一个测试锁定这个对应关系（`RankingChart` 或 `Dashboard` 的 `ranking` 状态是纯函数可测的，
  否则用一个断言文案与数据的测试）

**留白**：同一张图里行高约 64px、面板很宽但内容只占左侧。
`src/styles/pages.css` 里 `.ranking li` 相关规则需要收紧，让内容用上宽度。

## 问题 2：时间线部分胶囊未上色

**截图证据**：时间线里 `+ 7h 4m 33s`、`+ 2h 16m 10s`、`+ 2m 40s`、`+ 34m 59s` 都是**绿色文字**，
但 `4m 6s`（**首次导入历史**）只有浅色底、**文字不是绿色**。

**根因假设**：`src/styles.css` 里 `.event-initial_import .event-duration` 改成了
`background: var(--success-surface); color: var(--success)`（提交 `215857e`），
但可能有**更高优先级**的规则覆盖了 `color`。**先查有没有第二条规则** ——
这个仓库里卡片样式被声明过两份（`warmth.css` + `styles.css`），胶囊也可能是。

**要求**：让导入与增量在**颜色族上一致**（都是绿），可用不同深浅区分，**不能一个绿一个不绿**。

## 问题 3：「刷新观测」按钮图标与文字上下堆叠

**截图证据**：一个胶囊按钮里，刷新图标在**文字上方**，而不是左侧。
（图 3 是 276×143 的特写，图标和「刷新观测」上下两行。）

**根因假设**：按钮内的 `<svg>` 和文字之间没有 `display: flex; align-items: center`，
或某个规则把 svg 变成了块级。也可能是 `flex-direction: column` 被继承。

**要求**：图标与文字**同一行**、垂直居中。同一个按钮在**所有页面**都要检查
（实例观测、世界与玩家、统计页都有类似的带图标按钮）。

## 问题 4：实例观测的分页应针对具体实例

**截图证据**：实例列表（香草纪元 / GregTech Leisure-私货版 / gtl-continue / All the Mods 10）
下方是「第 1 / 3 页 · 共 43 条」+ 上一页/下一页。

**用户要求**：**翻页针对具体实例，而不是针对全部记录。**

**含义**（需在实现前用一句话向用户确认，或按最合理的方式做并说明）：
每个实例**自己分页** —— 即展开某个实例时，它的观测记录分页只在该实例内生效，
而不是把 43 条记录摊在一个全局分页里。

**涉及文件**：`src/components/ObservedSessions.tsx`（含 `InstanceObservation` 的列表）、
`src/components/InstanceObservation.tsx`。

**注意**：现有分页有 Playwright 断言（`scripts/qa-observation-flow.mjs` 里有
「pagination (51 rows)」的断言）。改行为**必须同步改断言并说明**。

## 问题 5：档案与备份卡片排版

**截图证据**：`档案与备份` 卡片里：

- **复选框巨大** —— 蓝色勾选框约 **80×80**，而正常应该是 16-18px
- 一行里「自动备份 / 保留自动备份 / [7 份 ▾] / [立即备份] / [打开备份目录]」**间距散乱、不对齐**

**根因假设**：复选框没有 `width/height` 约束，被 flex 容器拉伸（`align-items: stretch` 或
缺少 `flex: none`）。这一行里的控件高度也不一致。

**要求**：

- 复选框回到正常的 16-18px，`flex: none`
- 该行的控件**垂直居中对齐**、间距一致，且与卡片内其他行的节奏统一
