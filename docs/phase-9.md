# Phase 9：PCL 自动联动、时间线与更多统计

版本 0.9.0。按用户要求加强 PCL 联动并完成 Timeline 和其他统计。HMCL / Prism 仍暂缓，安装器和发行验收留到 Phase 10。

## PCL 自动联动

之前已有 Rust PCL Adapter，直接读取以下来源，不需要 PowerShell、批处理或其他外部脚本：

- `HKCU\Software\PCL\LaunchFolders`：PCL 已保存的跨盘游戏文件夹。
- 正在运行的 PCL 可执行文件所在目录，仅查询程序路径。
- 启动器的 `PCL/Setup.ini`：全局隔离设置。
- `versions/<实例>/PCL/Setup.ini` 与版本 JSON：隔离覆盖、Minecraft 版本和加载器信息。

本阶段增加 `launcher/sync.rs` 后台服务。程序运行时每 15 秒检查元数据，启动时及发现新增实例、版本变化或隔离变化后调用现有只读扫描和事务导入；没有变化时不重新扫描世界。Windows 路径在首次使用时即规范化，避免第二次检查误判变化。

已选择的配置目录优先，其次为唯一运行中的 PCL，再次为已导入实例的唯一有效 PCL 配置。多个启动器且尚未选择时提示选择，不推测。关闭 PCL 后仍可读取已保存配置。用户在 PCL 中新增的已登记文件夹也会进入下一轮检查；不搜索整块磁盘。

与手动扫描、文件观察器共享扫描许可，手动扫描优先。立即同步请求遇到占用会等待重试，即使自动同步暂停也能执行一次。暂停开关保存至档案，运行中的同步会检查取消信号。无法确认的配置显示问题并保留档案；不可访问文件夹保留历史。已从配置移除的实例显示历史保留标识，不删除世界历史。

界面增加：全局 PCL 联动状态条、当前实例数量、正在运行或已关闭状态、最近检查与同步时间、新增和配置变化数量、暂停开关、立即同步、配置来源详情、启动器目录选择，以及实例直达世界的入口。PCL 同步和存档自动追踪是两个独立开关。

## 时间线

从既有 SQLite 快照、增量与回档表读取，不生成虚构的游戏会话。事件包括：

- 首次导入历史：导入时读取的累计时长。
- 建立追踪基线：首次观察，新增时长为零；与同秒同内容的首次导入合并展示，旧档案升级后的独立基线保留。
- 观察到时长增长：相邻有效观察之间的正向差值。
- 统计回档：保留旧值和新值，新增时长为零。
- 其他统计变化：内容改变但时长未增加。

按观察时间和快照 ID 稳定倒序，每页 50 条；支持实例根目录、世界、玩家、起止日期及事件类型。日期使用本机时区，验证非法日期和倒置范围。首次导入时间不代表实际游玩日期，观察增量不等同于准确的完整会话。

Dashboard 显示最近 5 条，世界详情可直接进入对应世界的时间线。schema 4 事务升级至 schema 5，仅增加快照时间与世界玩家索引，不改变历史、增量和关联数据。

## 更多统计

以当前有效来源或首次历史快照为独立口径，支持实例根目录、世界和玩家筛选。当前来源排除已缺失世界和不可读统计；没有可读数据时显示暂无数据，不把缺失读数当作零。

显示游玩时长、死亡、跳跃、生物击杀、离开游戏次数、步行距离、疾跑距离和飞行距离。厘米精确换算为带两位小数的米，游玩时长精确到秒。Rust 使用 i128 汇总，IPC 用十进制字符串传递，前端使用 BigInt，避免大数精度损失。

通用分类表按 category / key 搜索，每页 100 项。整数值合计；对象、数组、字符串和浮点数不强行相加，展示最多 3 个有长度限制的值预览，完整原始内容仍保存在档案中。未知模组统计不会丢弃。共享根目录只统计一次，复制世界仍遵循 Phase 8 的复核约束，尚未扣减未知继承时长。
