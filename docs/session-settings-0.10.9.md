# 0.10.9 页面记忆与启动设置

- 首次访问页面后将组件保留在本次进程内。返回页面保留搜索、排序、分类、分页、组合筛选、展开状态和滚动位置；退出程序后重新初始化。不会把这些临时操作写入本地偏好。
- 概览、时间线、更多统计使用独立筛选状态。主动从某世界跳转到统计或时间线时，仍应用该世界的筛选。
- 统计和时间线在查询条件、最近扫描版本均未变化时复用已有数据；隐藏页面暂停查询，隐藏的排行图表释放绘图实例。
- 玩家列表打开时按已选置顶排列，打开期间冻结顺序。勾选不会重新排序或跳到顶部；下次打开时再把已选项置顶。
- “重新检查本页资源”是唯一发起资源解析的入口。切换主页面、分类、筛选、分页、搜索或重新启动不会自动检查。手动请求结果不会覆盖已换页的数据。
- 设置页以“启动与界面”“读取本地存档”分组，窄窗口自动单列，PCL 文件夹详情默认收起。
- Windows 自启动默认不启用。用户开启后写入当前账户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下 `MineChronicle` 值，使用带引号的当前程序路径；关闭时只删除本软件的值。启动路径显示实际注册路径。
- 开机启动与缩放属于持久设置，不受临时页面状态重置影响。

验证：

- 65 项前端测试通过；Rust 6 项单元测试和 7 项活动查询测试通过。
- 无界面 Edge 使用真实组件与模拟 IPC 验证筛选、分页保留，重复导航不查询，资源检查调用数仅随按钮点击增长，退出重载后清空临时状态。
- 35 名玩家的滚动列表中勾选第 20 名玩家前后，滚动位置和项目顺序完全一致。
- 自启动开关使用模拟 IPC 验证，不更改用户真实启动设置；Rust 测试验证带空格/中文路径的引号和路径长度校验。
- 125% 缩放检查设置页布局；未使用 Computer Use。
