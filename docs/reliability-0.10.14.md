# MineChronicle 0.10.14：可靠性、档案保护与历史查询

## 已实现

- 统一读取状态保留最后成功数据及更新时间，提供手动重试。后台失败按 3、10、30 秒退避，随后保持 30 秒；窗口隐藏期间暂停，重新显示补试。失效请求不会覆盖新筛选结果。
- 档案、运行信息和 PCL 目录独立加载，恢复读取不会覆盖已编辑的搜索目录。
- 设置新增身份、启动与显示、导入与联动、档案与备份、数据健康分区导航；路径默认折叠，数据健康保留在末端。沿用现有颜色、圆角、SVG 和减弱动画规则。
- 时间线和统计提供筛选摘要、清除本页筛选和空结果提示；跨页同步的玩家选择不会被清除。
- 观测支持实例路径、本地开始日期及状态筛选。首次查询固定最大 ID，新增记录只显示刷新提示；全部历史、筛选结果、本页小计分别展示。实例观测不按玩家筛选。
- 概览复用一次归因结果；归因按实例和时间索引匹配，保留同世界多玩家取最大值、15 分钟窗口、首次基线和重叠区间首次归属规则。观测查询仅在数据 revision、筛选或翻页变化时执行。

## 档案与备份

界面展示当前运行程序返回的实际档案路径和版本，不推断 AppData 位置。备份使用 SQLite backup API，包含已提交的 WAL 数据、所有数据库设置和历史记录，不包含 Minecraft 文件或图标缓存。

自动备份默认开启，启动时及运行期间每小时检查：每个本地日期最多成功创建一份内容变化的备份，不补造错过日期。默认保留最近 7 份，可选 14 或 30 份。自动策略和备份清单位于应用数据目录的 `backup-policy.json`，不会随档案恢复回退。

只有一致性、结构和版本校验成功的快照才纳入清单。清理只针对清单内、指定目录下且摘要未变的本功能自动备份；手动和恢复前备份不会自动删除。备份失败展示错误并保留旧备份。磁盘写入失败测试通过注入 `StorageFull` 完成，不会填满用户磁盘。

从备份列表选择文件或输入完整路径，先校验并预览日期、世界数、观测数和兼容性，再勾选确认。扫描或游戏运行时拒绝恢复。准备恢复会先备份当前档案，将选中文件暂存到档案所在卷；下次启动在后台服务启动前替换。保留原档案用于回滚，并处理替换中断、暂存损坏等情况。未在真实用户档案上执行破坏性恢复演练。

## 性能复现

运行 `cargo test --manifest-path src-tauri/Cargo.toml --release --lib --jobs 1 scale_report -- --ignored --nocapture --test-threads=1`。输出包括 10、1,000、10,000 条会话和配套增量的同机新旧归因时间、查询时间、返回行数、材料化会话行数、匹配 ID 数及进程工作集。

工作集是基准进程的瞬时值，不代表桌面应用峰值内存；材料化行数不是物理磁盘读取次数。数据库大小按 SQLite 页数计算，包含 WAL 中的逻辑页面。查询仍需读取历史以生成累计，未引入物化表或删除快照，也不声称消除了所有全量读取。计时只作同机对照，不作绝对性能门禁。

2026-09-18 本机 release 模式串行对照：

| 会话 / 增量     | 旧归因     | 新归因    | 观测查询（无增量样本） |
| --------------- | ---------- | --------- | ---------------------- |
| 10 / 50         | 0.014 ms   | 0.024 ms  | 1.657 ms               |
| 1,000 / 5,000   | 10.164 ms  | 1.544 ms  | 3.555 ms               |
| 10,000 / 50,000 | 966.989 ms | 17.408 ms | 31.837 ms              |

万条会话配五万增量时，归因约快 55.5 倍；小样本额外索引开销高于旧循环。查询材料化两份会话行及一份匹配 ID，返回最多 20 行；该规模下查询基准工作集约 12.0 MB，归因基准约 13.2 MB。查询样本与归因样本分开，不能将无增量查询时间视为含五万增量的端到端耗时。

最终结果及正常用户环境安装回执位于 `output` 下，避免提交用户档案和本地路径数据。安装验证必须通过正常 Windows 用户环境启动，并核对应用自身回执，避免 Codex 的 AppData 重定向。

本次已完成正常用户环境安装验证：前后端回执均为 0.10.14；97 个世界、53 个玩家、411 份快照及升级前全部观测记录保留，数据库所有设置的摘要完全一致。用户同意游戏运行期间升级；安装及关闭临时调试入口的两次重启新增了两条观测，旧记录未丢失。实际自动和手动备份均成功校验，最终启动已关闭临时调试端口。安装后程序与构建产物逐字节比较，仅有 Tauri 安装器预期的 `UNK` → `NSS` 包类型标记差异。
