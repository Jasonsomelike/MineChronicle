## 1. 总体印象

底子已经是「柔和顺眼」的：暖纸地 `#f5f3ef` + 白卡 + 1px 暖描边、静置卡片零投影、圆角收敛到 8px、五档字阶，密度没有被稀释——wide-settings.png 上 quiet 分组 + 行 hairline 的分区语言、wide-dashboard.png 上 hero 面板的发丝线分区都成立。距离目标差的是三件「unfinished business」：**其一，暖化只改了手写 CSS**，antd 主题桥还停在旧冷 Arco 调色板，仓库自己的同步守卫实测红灯（3 failed），下拉框、开关、Segmented、次级按钮在暖纸面上描冷灰边、用冷蓝灰文字，深色下库控件 `#232324` 嵌在 `#24231f` 卡片里成了一块块色温不同的补丁；**其二，边界语言有残留越界**：仪表台总览面板是全 app 唯一还带静置阴影的卡片（wide-dashboard.png 中明显微浮于纸面）、时间线与世界行的行分隔被遗留基线叠成 2px 双线、测量条一半有硬描边一半裸奔（wide-worlds.png 的 QA World 条是 600px 全饱和裸色带）；**其三，色彩温度有杂质**：时间线芯片的冷薄荷/冷粉 tint（wide-dashboard.png）和统计页 8+ 个松绿首字徽章（wide-statistics.png）是页面上最跳的元素，盖过了本该唯一的强调色。修掉这三类，柔和与边界感同时成立，且全部是令牌与个位数 CSS 行的改动，不动版式。

## 2. 流行趋势摘录

两份调研的要点按对本项目的适配度筛选（代表产品注明；【转述】处见证据约定）：

1. **描边分层，不靠投影**（Linear / Notion / shadcn / Vercel Geist / Radix）：静置卡片 = 1px 低对比描边（前景色 6–14% 透明度，对卡面 1.1–1.5:1）+ 同色系浅一档底色；投影只留给真正浮起的层。Geist z-1：`0 0 0 1px #ebebeb, 0 1px 2px rgba(0,0,0,0.05)`（#ebebeb 对白 1.19:1）——本项目浅色 `#e6e2da` 对白卡 1.29:1、深色 `#35322c` 对卡面 1.23:1，都在业界参数带内，**浅色描边不用动**。
2. **端点带微暖**（Raycast / shadcn dark）：近黑不是黑、近白不是白，中性色 chroma ≤0.01。本项目 `#f5f3ef` / `#191816` 已满足，**不动**。
3. **配对阴影**（Raycast / Linear / MDC）：浮层 = 一层极细接触层 + 一层微环境层，模糊 ≤14px；Linear 暗色完全弃用投影，靠表面阶梯。ant design 静置/弹层两级阴影、Geist z-2 hover 阴影是现成参照。
4. **圆角递进、嵌套递减**（Material 3 / Raycast / shadcn / Radix）：控件 < 卡片，嵌套圆角 = 外圆角 − 内边距。高密度工具取小半档更顺眼。
5. **强调色只买交互与数据**（Things 3 / Notion / Linear）【转述】：克制不是把强调色调淡，而是减少它的面积与场合；hover 不换色相，只做中性底色步进；选中底色用 `color-mix(in oklch, var(--accent) 12%, var(--surface))` 这类色混而非新色值。
6. **小台阶字阶 + 500 字重 + 正字距**（Raycast）【转述】：小字号配 500 字重补笔画分量，正文行高 1.5–1.6、标题 1.2，微标签 +0.2~0.4px 字距，muted 文本一档到位——密度靠分组节奏而不是压缩间距。
7. **深色模式：表面色阶 + 提亮描边，阴影归零**（Geist / shadcn）：越浮越亮的 surface 阶梯 + 一条比卡面略亮的描边（8–14.5% 白合成量）；本项目现行 warmth.css 体系与这条完全同构，可补的是把深色描边提半档。

> 落地提醒（来自调研的 antd 6 结论）：覆写走 `ConfigProvider` token（即本仓 `src/lib/antdTokens.ts`），不要在组件 CSS 里对抗库的运行时注入样式；v6.3+ 弹层 mask blur 默认关闭。

## 3. 核心问题（跨界面归并）

### A. 色彩与对比

**A1 · antd 主题桥整体漂移，同步守卫红灯**【本轮实测】— `src/lib/antdTokens.ts:77-99`（light）、`:130-146`（dark）、`:115-121`（components.Tabs）
桥接层仍是冷 Arco 值：`colorPrimary #0f766e`、`colorBgLayout #f7f8fa`、`colorBorder #e5e6eb`、`colorBorderSecondary #f2f3f5`、次级文字 `#4e5969`、禁用底 `#f2f3f5`；dark `#17171a/#232324/#2a2a2b/#333335/#2e2e30`、Tabs 选中 `#7fd4c0`。而 warmth.css 已迁暖：`#0d6e63/#f5f3ef/#e6e2da/#efece6/#57544c`；dark `#191816/#24231f/#2c2b26/#35322c/#302e28`、accent `#6fc9b4`。该文件头部自称 "one shared source of truth"，`antdTokens.test.ts` 就是为此设的门禁——现在真的红了（3 failed / 5 passed，`npm run verify` 必红，违反 brief §2.7）。可见后果落在每处缝合：wide-timeline.png 的三个下拉与日期框、wide-settings.png 的主题 Segmented、wide-observation.png 的开关，在暖纸面上全是冷灰描边；SessionEndDialog 里手写输入框（`--border-input #ccc6ba`）与 antd 按钮（冷边）同框。

**A2 · 灰阶双温度：两个色温的中性灰同屏等权共存** — `src/warmth.css:85-88`（`--text-hint/--text-caption/--text-caption-warm/--text-summary` 全为冷蓝灰 `#4e5969`，h216 s15%）对照 `:59`（`--text-muted #57544c`，h44 s7% 暖橄榄）、`:63`（`--text-label #272e3b` 冷藏青）。同屏相邻实例：`.tracking-state article > span` 用冷 `--text-summary`（warmth.css:451）而紧随的 `.tracking-state p` 用暖 `--warm-muted`（:462），wide-dashboard.png 统计范围区域；`styles.css:3236` 的 `.status-center-hint` 也是冷灰。暖纸底上说明性文字轻微发蓝，是「不明原因不协调」的来源。

**A3 · 一绿多名** — `src/warmth.css:32,53`（`--brand/--surface-strong #0d6e63`）vs `:106`（`--chart-bar #0f766e`）vs `:112`（`--focus-ring #0f766e`），antd `colorPrimary` 又独立用 `#0f766e`（antdTokens.ts:77）。同一强调色以两个数值（ΔRGB≈2,8,11）、四个身份存在；`:18-19` 注释还在写「#0F766E: 5.47:1 on white」，而在用的 `#0d6e63` 实测 6.13:1【本轮实测】。另注意 `--surface-strong` 与 `--brand` 浅色同值却是两个名字（消费者见 P1-1），收敛时必须把关系写明，否则执行者会自行发明第三种处理。

**A4 · 浅色语义 tint 是整页最跳的冷色块** — `src/warmth.css:73-75`（`--success-surface #e8ffea` 薄荷、`--danger-surface #ffece8` 冷粉），叠在暖纸面上；wide-dashboard.png 与 wide-timeline.png 的时间线芯片肉眼可见地盖过品牌绿图表条。文字对比达标（`#008026` on `#e8ffea` 4.84:1、`#cb272d` on `#ffece8` 4.76:1【本轮实测】），深色同角色却是精心预合成的暖底（`#24432b/#4d3131`，warmth.css:193/195）——两套主题处理深度不一致。

**A5 · 强调色买了不该买的东西** — ① `src/components/Statistics.tsx:332-353` + `src/styles/pages.css:291、448-462`：占位图标的首字徽章用 `--surface-strong` 松绿实心填充 + cutout 阴影，首字又与紧邻标签完全重复，wide-statistics.png 一屏 8+ 个绿点是全页最响元素；② `src/styles.css:3834-3837` `.health-pending` 把「N 项待处理 · 0 条确认关联」整串染强调色 + 600 字重（DataHealth.tsx:241-246 把类挂在整个 span 上），中性后半句被一起染色；③ `src/styles.css:1405` 排行行 hover 用品牌系薄荷 `--surface-info`（见 C2）。

**A6 · 深色边界只有单层且更弱**（无实拍，代码 + 计算）— `src/warmth.css:138-141` 深色四枚 elevation 阴影全为 none 后，深色分层只剩「卡面对页底 1.13:1（#24231f on #191816）+ 边框对卡面 1.23:1」，抬升面对卡面（#2c2b26 on #24231f）也只有 1.11:1【本轮实测计算，node 逐对】，比浅色的双层（白卡对纸面 1.11 + 边框对卡面 1.29）弱半档。另 `:150-153` 深色 `--surface-sunken` 与 `--page` 同为 `#191816`：世界页/时间线直接坐在 page 底上，时长条轨道、`.event-merged-tag` 填充、`.list-empty` 井在深色下全部消失（`src/styles/pages.css:172`、`src/styles.css:2007`、`pages.css:16`）。

### B. 卡片与边界语言

**B1 · 仪表台总览面板是全 app 唯一静置带阴影的卡片** — `src/styles.css:1300` `box-shadow: var(--shadow-card)`。warmth.css:409-411 的契约是 "Resting cards: no elevation shadow in either theme"，brief §6 把 resting 卡片带阴影列为退役项，2026-09-23 step 2 已从 settings-card 与 dashboard 面板摘掉——合并成总览面板时这行漏网。wide-dashboard.png 中该面板明显微浮于纸面，与设置卡、ranking 面板的纯描边语言同屏混用。

**B2 · 行分隔被遗留基线叠成 2px 双线** — ① 时间线：裸 `li` 基线 `border-top`（`src/styles.css:748`）+ `.timeline-events > li` 自身 `border-bottom`（:1945-1954）相邻行叠成 2px `#e6e2da` 双线，首行上方多一条无人声明的开线、末行按 :last-child 无底线——列表的开合框架是意外拼出来的；同一根因还给 `.event-parts li`（:2116-2123，自己未声明边框）每个明细行加了顶线。② 世界行：同一元素（antd Collapse 根）同时带 `border-top`（`styles.css:1009-1012`）与 `border-bottom`（`src/styles/pages.css:130-133`），两根不同 token 的线叠成 2px；像素实测 wide-worlds.png x=700 纵扫：y=397 `#EFECE6` + y=398 `#E6E2DA`，末行只剩单根。（复核补充：游戏实例页的 `.instance-worlds li` 也从裸基线继承顶线、与自身底线叠成同族 2px，见 P0-4①。）

**B3 · 测量条家族两种重量** — 仪表台 `.ruler-track` 用 `outline: 1px solid var(--text-faint)`（文字灰，3:1 取舍成立，`src/styles.css:492`）；世界页 `.world-mini-bar`（`src/styles/pages.css:165-181`）同是 sunken 底却无任何描边，fill 是 600×5px 全饱和裸色带（wide-worlds.png x=700 扫描 y=346-350 五像素全饱和【截图】），track 对页面仅勉强可辨。同一「仪器读出」家族，一半硬边空心框、一半无边柔和条。

**B4 · 浅色 tint 面板与页面同色，边界只剩一根线** — `src/warmth.css:36,43`：浅色 `--surface-tint` 与 `--page` 同为 `#f5f3ef`，所以 `.observation-summary`（styles.css:3040-3053）、`.observed-sessions`（:3001-3007）、`.stat-icon-details`（:2320-2327）的内里与页面地板同色，wide-observation.png 里「实例观测时段」面板读作纸面上的空框，与上方白 watch 条、下方白 QA Instance 卡形成三种并存的卡片画法。深色下同一 token 有真实抬起（`#2c2b26` on `#191816`），问题只在浅色。另 `.observation-summary` 浅色是凹（比白卡深一档）、深色是凸（`#2c2b26` 比卡面亮一档）——同一语言换主题翻转深度方向（代码推导，无深色实拍）。

**B5 · 三个提示块直角，脱档于全 app 圆角语言** — `src/styles.css:1139-1145`（.scan-issues）、`1488-1494`（.empty-stats）、`2970-2974`（.lineage-note）没有 border-radius；同族 `.scan-notice`（:988）、`.background-warning`（:3291）、`.next-step`（:762）、`.import-summary`（:1132）都是 `--radius-sm`。wide-settings.png / narrow-settings.png 里「需要复核」琥珀块方角紧贴上下圆角块。另 `.empty-stats:1490` 的 `border-left: 3px solid var(--border)` 是不编码语义的中性装饰条（.scan-issues 的琥珀左条编码警告语义，应保留）。

### C. 圆角、阴影与悬停（组件一致性）

**C1 · antd 小圆角档错位一档** — `src/lib/antdTokens.ts:60-66`：注释称对齐 CSS `--radius-xs/sm/md/lg = 2/4/8/8`，实际 `borderRadiusSM=2`（= CSS xs），CSS 同档 `--radius-sm` 是 4px；测试把 SM=2 写死成期望（antdTokens.test.ts:114-119）。Switch、Segmented item 等 antd 小控件 2px 圆角与同尺寸手写控件 4px（warmth.css:365,475）并排时差一档；注释与值不符。

**C2 · 悬停三套语言** — ① 排行行 hover 染薄荷：`src/styles.css:1404-1406` `background: var(--surface-info)`，warmth.css:488-490 对同一选择器写的是中性 `--surface-hover`；styles.css 后导入（main.tsx:13-14）同特异性胜出，排行行成了全 app 唯一 hover 发绿的列表行（时间线 :1955-1957、统计表 :2575-2577、picker :1863-1865、观测分组 :3739-3741、世界结果 :1025-1027 全是中性 hover）。② antd default 按钮 hover 把文字和边框一起染成 `colorPrimaryHover`（且因 A1 还是旧松绿派生），底色不变——与手写控件「中性底色步进」（styles.css:946-948, 2886-2888）不同套，wide-settings.png 档案卡内三枚 antd 按钮与旁边开关同框两套反馈；`.text-button` 的下划线 hover（styles.css:612-616）被 antd 更高特异性选择器压住不再渲染。③ 时间线行 hover 是全宽直角色带（styles.css:1955-1957）与世界行的圆角内缩胶囊（pages.css:543-553）词汇不一，且时间线 hover 底 `#EFECE6` 与 `.event-merged-tag` 的 sunken 填充（styles.css:2003-2012）几乎同色，悬停时标签填充被吃掉。

**C3 · antd 迁移残留的死规则与破角** — ① SessionEndDialog 已迁 antd Modal，但 `src/styles.css:3629-3643` 把原生 dialog 的 border/radius/shadow 打在 `.ant-modal` 外壳上，`.session-end-dialog::backdrop` 对 div 遮罩永不生效——实际遮罩是 antd 默认 `rgba(0,0,0,0.45)`，比 `--wash-a` 重得多；外壳 4px 圆角与内容 8px 圆角错位，弹窗四角边界感是破的。styles.css:2610 的 StatIconPreview `::backdrop` 同样失效。② `.health-tabs`（styles.css:2889-2904）现在是 antd Tabs 根，却带着手写 border-bottom + button 选中填充规则：button 选择器在 antd DOM 上匹配不到（死规则），antd nav 自带 `::before` 底线与根上 `--border` 线相距 12px 平行成双线；选中色实际来自漂移的 `#7fd4c0`。③ SecondaryButton 静息画法（styles.css:941-948，(0,1,0)）输给 antd 注入的 `.ant-btn.ant-btn-variant-outlined`（(0,2,0)），只有 `.scan-panel` 内的暖底（warmth.css:359，(0,3,0)）赢回来——同一「secondary 按钮」两种相貌。④ 焦点两套几何：手写 3px 实线 + 2px offset（warmth.css:347-350）vs antd 0 0 0 2px 低透明光晕（无 offset），暗色下后者从深绿派生近似不可见（未实测对比度，如实标注）。

### D. 间距、字号与读数

**D1 · 701–900px 断点空档：hero 大数字贴边** — `src/styles.css:1526-1528` ≤900px 块把 `.career-total` 水平内边距清零（`padding: 20px 0`），覆盖它的 700px 块只管 ≤700。审阅方在 800×900 实测：hero 大数字 `strong` 盒距面板边框仅 1px，与下方 ruler 的 24px 左缘错位（同面板 `.tracking-state` 是 20/24、`.overview-ranking` 是 16/24）——面板内容顶到边界，边界感直接破。

## 6. 落地顺序与注意事项

**顺序（每批独立可验收）：**

1. **批次一 · 令牌归一（P0-1 + P1-1，约半天）**：先 antdTokens.ts 对齐，再 warmth.css 灰绿别名收敛。两者都是纯值替换，下游一切自动继承。验收：`npx vitest run src/lib/antdTokens.test.ts` 8/8；`node scripts/qa-design-check.mjs` 全绿。
2. **批次二 · 边界语言（P0-2 + P0-4 + P2-1，约半天）**：去阴影、hover 去薄荷、叠线归一、直角补圆。验收：wide-dashboard / wide-timeline / wide-worlds / wide-instances 重截对比，行分隔像素扫描应只扫到单根 1px 线（wide-instances 验证 .instance-worlds 失去继承顶线后的单根底线）。
3. **批次三 · 几何与断点（P0-3 + P1-5，约半天）**：footer grid-column、701–900 padding、读数 nowrap。验收：800×900 与 620px 各截一张；设置/仪表台滚动到底截图确认无叠印。
